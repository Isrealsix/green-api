# Green API

Веб-чат для отправки и получения текстовых сообщений в мессенджере MAX через [GREEN-API](https://green-api.com/max).

**Демо:** [https://greenizi.netlify.app](https://greenizi.netlify.app)

Стек: React, TypeScript, Vite, Zustand.

## Возможности

- Вход по `idInstance` и `apiTokenInstance` с проверкой состояния инстанса
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений методом [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/)
- Получение ответов через [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/) (`ReceiveNotification` и `DeleteNotification`)
- История чатов сохраняется в браузере
- Светлая и тёмная тема, адаптивная вёрстка для телефона

## Требования

- [Node.js](https://nodejs.org) версии 18 или новее (npm устанавливается вместе с ним).

- Аккаунт в GREEN-API с инстансом MAX
- Второй аккаунт MAX (на другом телефоне), чтобы отвечать на сообщения при проверке

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <ссылка-на-репозиторий>
   cd <папка-проекта>
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите проект в режиме разработки:

   ```bash
   npm run dev
   ```

4. Откройте в браузере [http://localhost:5173](http://localhost:5173).


## Настройка GREEN-API

1. Зайдите в [личный кабинет GREEN-API](https://console.green-api.com) и создайте инстанс MAX.
2. Авторизуйте инстанс: в приложении MAX на телефоне откройте **Профиль > Устройства > Войти по QR-коду** и отсканируйте QR-код из личного кабинета. Дождитесь, пока инстанс станет авторизованным.
3. Откройте настройки инстанса:
   - поле **Webhook Url** оставьте пустым
   - включите **Получать уведомления о входящих сообщениях и файлах**
   - включите **Получать уведомления о сообщениях, отправленных с телефона**
   - сохраните настройки и подождите около минуты, пока они применятся
4. Скопируйте **idInstance** и **apiTokenInstance** со страницы инстанса.

## Как пользоваться

1. Войдите, указав `idInstance` и `apiTokenInstance`. Поле `apiUrl` можно оставить пустым: по умолчанию адрес определяется по первым 4 цифрам `idInstance` (например, `3100...` даёт `https://3100.api.green-api.com`). Если в личном кабинете указан другой `apiUrl`, введите его.
2. Нажмите кнопку нового чата и введите номер получателя в международном формате, например `+7 999 123-45-67`.
3. Напишите сообщение и нажмите Enter (Shift+Enter для переноса строки).
4. Ответьте с телефона получателя. Ответ появится в этом же чате через пару секунд.
